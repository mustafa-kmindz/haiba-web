## 📊 The Funnel

```
Email Sent
   ↓
   ├─ Opened (25-30%)
   │  ├─ Clicked (14-17% of opens)
   │  │  └─ Landed on landing.html
   │  │     ├─ Viewed form (60-70%)
   │  │     │  └─ Filled form
   │  │     │     └─ Submitted ← CONVERSION
   │  │     │        └─ Thank you page
   │  │     │           └─ Sales outreach
   │  │     │              └─ Kickoff call
   │  │     │                 └─ POC build
   │  │     │                    └─ Go-to-production
   │  │     │
   │  │     └─ Scrolled POC page (50-60%)
   │  │
   │  └─ Not clicked
   │     └─ Day 3: Email 2 sent
   │
   └─ Not opened
      └─ Day 7: Email 3 sent
```

**Expected Conversion:** 0.5-0.6% (6-10 qualified leads from 1,000 emails)

## 🚀 How to Get Started

### Step 1: Setup (2 hours)
1. Read `QUICKSTART_GUIDE.md`
2. Get Mailerlite API key
3. Update `process-lead.php` with API credentials
4. Test form submission on `landing.html`

### Step 2: Mailerlite Configuration (2 hours)
1. Create "POC Inquiries" list/group
2. Upload `email-template.html` to campaign
3. Create 3 email sequences (see guide)
4. Set up automation triggers

### Step 3: Launch (1 day)
1. Send pilot to 500 contacts (Monday)
2. Monitor open/click rates (Tuesday)
3. Optimize subject line (Wednesday)
4. Scale to full list (Friday)

### Step 4: Manage (Daily/Weekly)
- Daily: Check new form submissions
- Daily: Sales outreach to leads
- Weekly: Analyze metrics, optimize
- Monthly: Full funnel review
