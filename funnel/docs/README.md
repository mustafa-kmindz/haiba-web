This folder contains the complete **email marketing funnel** for offering free proof-of-concepts to innovators, entrepreneurs, and intrapreneurs.

## 📁 Folder Structure

### Live Pages
```
landing.html       → Lead capture form (main conversion page)
poc.html          → POC details, FAQ, success stories
thank-you.html    → Post-form confirmation
```

### Email Template
```
email-template.html    → Ready-to-copy HTML for Mailerlite campaigns
```

### Backend Processing
```

```

### Documentation & Guides

## 🚀 Quick Start (5 minutes)

1. **Read:** `QUICKSTART_GUIDE.md`
2. **Setup:** Get your Mailerlite API key
3. **Configure:** Update `process-lead.php` with credentials
4. **Test:** Submit a test form on `landing.html`
5. **Launch:** Copy `email-template.html` to Mailerlite and send!
