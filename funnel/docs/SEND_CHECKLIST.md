## Sending Instructions

### Via Gmail
1. Open Gmail compose
2. Click "⋯" menu → "Plain text" mode (if needed)
3. Create new email
4. Paste template HTML into body
5. Set subject line: "Your $Million Idea Starts Here 💡"
6. Add preheader: "Your Idea. Our Execution. Shared Success."
7. Review preview
8. Schedule or send

### Via Outlook
1. New Email
2. Format → HTML
3. Insert → Online Pictures → Choose downloaded template
4. Or: Insert → Text from File → Select HTML file
5. Set subject line
6. Preview in different views
7. Send

### Via Email Marketing Platform (Mailchimp, ConvertKit, etc.)
1. Create new campaign
2. Select "Code Editor" template
3. Paste entire HTML content
4. Personalize if needed
5. Set segmentation/audience
6. Schedule send
7. Monitor open rates & clicks

### Via HTML Email Signature Service
1. Upload HTML template
2. Set as template
3. Create new email from template
4. Customize message if needed
5. Send

## Common Issues & Solutions

**Issue:** Email displays with black text on dark background
- **Solution:** Template is designed for supported email clients. If seen in unsupported client, use light template instead.

**Issue:** Buttons not clickable
- **Solution:** Some clients may need HTML re-encoded. Try sending via platform that handles HTML properly (Mailchimp, etc.)

**Issue:** Images not loading
- **Solution:** This template uses no external images. If seeing broken image icons, clear cache and resend test.

**Issue:** Layout broken on mobile
- **Solution:** Template is responsive. If issue persists, check email client's mobile rendering. Test in different phones.

**Issue:** Colors different in preview vs sent
- **Solution:** Different email clients render CSS differently. This is normal. Test in target client before final send.
